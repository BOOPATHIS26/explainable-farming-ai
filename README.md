# 🌾 Explainable Farming AI

A Streamlit app that recommends crops based on soil and weather conditions, with SHAP-based explainability.

## Features
- Crop recommendation using Random Forest
- SHAP waterfall plots for explainability
- Risk warnings for extreme conditions
- Interactive sliders for soil & weather inputs
